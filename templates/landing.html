package vault

import (
    "std"
    "gno.land/p/demo/avl"
)

// Persistent AVL Tree holding document hash -> metadata
var fingerprints avl.Tree

// RegisterFingerprint anchors a SHA-256 hash into Gno VM state
func RegisterFingerprint(hash string) string {
    caller := std.PrevRealm().Addr()
    if fingerprints.Has(hash) {
        panic("fingerprint already anchored in vault")
    }
    blockHeight := std.GetHeight()
    fingerprints.Set(hash, Record{
        Submitter: caller,
        Height:    blockHeight,
    })
    return "anchored_at_block:" + std.Itoa(blockHeight)
}

Common Questions

Frequently Asked Questions

Does anyone see my invoice amount, bank details, or client name?

No. The SHA-256 hashing algorithm is a one-way cryptographic function. Only the 64-character hexadecimal digest is recorded on Gno.land. It is mathematically impossible to reverse-engineer or reconstruct the invoice content from the hash.

What happens if someone modifies a single comma or dollar value in the PDF?

Due to the cryptographic "avalanche effect", altering even a single bit in the file results in an entirely different SHA-256 fingerprint. The verification portal will immediately detect the mismatch and confirm the document has been tampered with.

Do I need GNOT tokens to verify an invoice?

No! Public verification is completely free and requires zero gas. It queries the Gno.land node state directly via read-only ABCI RPC calls. Only anchoring a new document requires a tiny gas fee signed via Adena.

Can I use this without a crypto wallet?

Yes. The platform supports a hybrid architecture: you can register with a standard email/password to generate and archive cryptographic audit certificates, or connect an Adena wallet for sovereign non-custodial on-chain signing.
